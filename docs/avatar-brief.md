# CombFlo 提案三｜角色頭像需求清單

網站裡 13 位角色都需要一張頭像，用在：右側「工廠裡的人」清單、點開角色後的檔案卡、環節卡片裡「在這裡工作的人」。

請產出後存成：

```
proposal-v3/public/avatars/<編號>.png
```

檔名對了就會自動取代目前的「色塊＋姓氏」預設頭像，不需要改程式。

## 共通規格

- **尺寸**：正方形 512 × 512 px，PNG。
- **構圖**：胸像（頭頂到胸口），臉在畫面中央偏上，四周留 8% 空白；網站會裁成圓形，四個角不要放重點。
- **背景**：單一純色，用下表的「背景色」（不要漸層、不要場景）。
- **風格**：請依另外提供的參考風格素材。表情要清楚，讓人一眼看出「優化前」的心情（頭像只做一張，以平常的表情為主，可以帶一點角色的個性）。
- **與 3D 角色一致**：髮型、眼鏡、安全帽、衣服顏色要和下表一致，因為地圖上的 3D 小人是照這份設定做的。
- **不要**：文字、Logo、真實品牌、真實人物的長相。
