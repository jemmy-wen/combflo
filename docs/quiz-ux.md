# 測驗頁設計原則（提案三）

測驗頁要同時有「心理測驗」的輕鬆感，和「表單」的確實感。依下列常見的表單與問卷 UX 原則調整：

| 原則 | 這一版的做法 |
|---|---|
| 一次只問一件事（one thing per page） | 一頁一題，題目字級放大，選項以外沒有其他干擾 |
| 選項就是按鈕（大點擊範圍） | 整張卡片可點，手機上也好按；每個選項有 A、B、C 字母 |
| 減少操作步驟 | 單選題選了自動前進（約 0.4 秒，先給選取回饋再跳頁）；複選題才需要按「下一題」 |
| 告訴使用者為什麼要問 | 每題下面一句「為什麼問這題」，降低猶豫 |
| 顯示進度與剩餘時間 | 頂部分段進度條（三個部分有間隔），側欄顯示剩餘約幾分鐘 |
| 允許回頭、可修改 | 「上一題」永遠可用；結果頁有「回顧我的作答」，可直接跳回某題修改 |
| 鍵盤可操作 | A–G／1–7 選擇、Enter 下一題、← 上一題 |
| 自動暫存 | 作答存在瀏覽器，重新整理或離開再回來不會不見 |
| 先給價值，再要資料 | 不用留資料就能看結果；結果頁下方才出現聯絡表單 |
| 表單欄位最少化 | 只留 6 個必要欄位；地區、人數、時段改成可點選的選項，不用下拉選單 |
| 錯誤訊息貼近欄位、用白話 | 送出時沒填的欄位標紅、旁邊寫「請填寫」，不清空已填內容 |
| 開放題給範例 | 最後一題提供 3 個範例句，點一下就能帶入，也可以跳過 |
| 與主視覺連結 | 側欄顯示「這題對應工廠裡的哪個環節」，延續首頁的流程工廠情境 |
